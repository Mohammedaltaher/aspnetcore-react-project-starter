# Feature definition of done

- [ ] Requirement and acceptance criteria are recorded.
- [ ] Database model and migration are reviewed.
- [ ] API contract, validation, and server-side permissions are complete.
- [ ] Unit and integration tests cover critical paths and unauthorized access.
- [ ] React UI uses the real API and handles loading, empty, success, and error states.
- [ ] Frontend build and tests pass.
- [ ] Documentation, security checks, and deployment verification are complete.
